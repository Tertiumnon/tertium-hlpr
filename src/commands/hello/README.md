# Hello Commands

Terminal demo commands.

## Platform Support

- ✅ **Linux** - Fully supported
- ✅ **macOS** - Fully supported
- ✅ **Windows** - PowerShell, Command Prompt, or Windows Terminal

## hello

Type the classic Wake Up Neo sequence, then display a short Matrix rain animation.

```bash
hlpr hello
```

## world

Display animated `Hello World` ASCII art.

### Usage

```bash
hlpr hello world
```

### Example

```bash
$ hlpr hello world
 _   _      _ _        __        __         _     _
| | | | ___| | | ___   \ \      / /__  _ __| | __| |
```
